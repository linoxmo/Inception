## Project Description

<span style="font-size: 130%;">This section presents the different key notions of the Inception project:</span>

### Virtual Machines vs Docker:

<span style="font-size: 130%;">A Virtual Machine is a simulation of the software of a computer based on the hardware of the computer it's used on. It creates its own OS. It offers total isolation from your computer.

Docker uses Containers, local environments that share the operating system of your computer. Because of that, it's more lightweight, but it's only partially isolated from your computer. Containers are created with Docker images, which are read-only templates. To build your own image, you create a Dockerfile with a simple syntax for defining the steps needed to create the image and run it with the command docker run </span>

### Secrets vs Environment Variables

<span style="font-size: 130%;">Secret Variables are Variables that you want to encrypt/keep private, like passwords. Variables are Public variables like names or emails.

</span>

### Docker Network vs Host Network

Docker Network is by default a bridge network > It's a virtual Network that simulates IP addresses, and is independent from your host's network. Containers can communicate on the same simulated networks with the same IP address. Your connection is smoother than when using Host network.

### Docker Volumes vs Bind Mounts

<span style="font-size: 130%;">

Docker Volumes store persisting data generated by containers. They are managed by Docker and normally stored in /var/lib/docker/volumes/ on Linux. They can be shared among multiple containers and are easier to back up and migrate.

Bind mounts allow you to mount a file or directory from the host machine into a container. The file or directory is referenced by its absolute path on the host machine. It's directly mapped to the host filesystem, so it gives full control of the host path. It can access and modify host files directly. Performance depends on the host filesystem, and it may have different behavior across operating systems

as different security considerations.

</span>
